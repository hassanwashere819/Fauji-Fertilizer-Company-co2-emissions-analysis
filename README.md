# Fauji-Fertilizer-Company-co2-emissions-analysis
This project analyzes CO₂ emissions from Fauji Fertilizer Company’s vehicle fleet using data from 2019–2022. I examined vehicle fleet size, distance travelled, fuel consumption, and CO₂ emissions to understand changes in emissions over time and the relationship between operational factors.

I cleaned and prepared the dataset, performed exploratory data analysis and visualization, analyzed correlations between numerical variables, and examined CO₂ emissions for trends and outliers. I then applied time-series analysis using ARIMA to forecast CO₂ emissions for the following five periods.
